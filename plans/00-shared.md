# Shared contracts — read this before your own plan

Three agents build the Hype Arena system in parallel. This file is the merge
contract. It is committed to `main` together with `arena/model.py` **before**
anyone branches. Neither file is edited on an agent branch.

Deadline: PR open before **29 Oct 2026, 11:00** (Europe/Bucharest). No pushes
after that. Merge order and the integration checklist are at the bottom.

## 1. Repository layout and ownership

Every path has exactly one owner. You never create, edit or delete a file
outside your owned paths. If you need something from another agent, code
against the interface in §3 and use a stub in your own `tests/<letter>/` folder.

## 2. Hard rules every agent follows

- Python 3.12, **stdlib only** inside `arena/` (`re`, `json`, `csv`, `dataclasses`,
  `datetime`, `bisect`, `heapq`, `signal`, `os`). Build-time tools under `build/`
  may use anything (pandas, an LLM API), but nothing from there is imported at run time.
- No model of any kind at run time. If you are tempted to add a classifier,
  write a weighted rule instead and note it in your plan's "deferred" section.
- Pure functions where possible; no module-level state except loaded data.
- Every public function in §3 has a docstring restating its contract and at
  least one test in your `tests/<letter>/`.
- Nothing prints at run time except through `arena/__main__.py` (owner C).
- Run `python -m pytest tests/<letter>` green before every push.

## 3. Interfaces (the only things agents call across the boundary)

All types come from `arena/model.py`.

### Owned by A

```python
# arena/lexicon.py
class Lexicon:
    @staticmethod
    def load(path: str) -> "Lexicon": ...
    subjects: dict[str, list[str]]            # canonical name -> attribute list
    events: set[str]                          # canonical event names
    aliases: dict[str, str]                   # lowercased alias/name -> canonical
    def resolve(self, name: str) -> Optional[str]: ...        # any case/spacing
    def has_attribute(self, subject: str, attr: str) -> bool: ...
    def find_mentions(self, sentence: str) -> list[Mention]: ...
        # whole-word, case-insensitive, LONGEST match wins, non-overlapping,
        # "Hooly AI Pro" never yields "Hooly"
    def event_date_attr(self, event: str) -> Optional[str]: ...  # "date" or None

# arena/pages.py
def load_universe(path: str) -> list[Page]: ...
    # rows grouped into pages = maximal runs of consecutive ids sharing a date
def split_sentences(text: str) -> list[str]: ...   # value-forms.md rules + abbreviations

# arena/grammar/sentences.py
def clauses(sentence: str) -> list[tuple[int, int]]: ...   # spans split at . , ; : ! ? • · |
def negated_before(sentence: str, pos: int) -> bool: ...   # negation earlier in same clause
NEGATION_WORDS: frozenset[str]
TIME_WORDS: frozenset[str]            # ago, yesterday, ..., "used to", "last week"...
MONTH_WORDS: frozenset[str]

# arena/grammar/values.py
def parse_values(sentence: str) -> list[ParsedValue]: ...
    # every readable value in the sentence, with flags; ambiguous forms -> omitted
def format_value(v: Value) -> str: ...
    # canonical written form the referee reads back as exactly v:
    #   money   "€59 per month" / "€299.99" ; quantity "128 GB" / "12 languages"
    #   percent "99.9%" ; date "12 March 2026" / "March 2026" / "2026"
    #   version "v2.3" ; duration "14 days" ; name as-is ; boolean -> raises (use attribute words)
def same_value(a: Value, b: Value) -> bool: ...      # after unit conversion, referee rules
def compare_values(a: Value, b: Value) -> Optional[Literal["gt", "lt", "eq"]]: ...
    # None when not comparable (names, booleans, different currency/period, month vs day)

# arena/grammar/claims.py
OP_PHRASES: dict[str, list[str]]       # {"gt": [...], "lt": [...], "eq": [...]} amount phrases
DATE_OP_PHRASES: dict[str, list[str]]
EVENT_PHRASES: list[str]               # at, during, on the day of, at the time of
def attribute_words(attr: str) -> str: ...   # soc2_certified -> "SOC 2 certified"
def find_op_phrase(sentence: str) -> list[tuple[str, int, int]]: ...   # (op, start, end)
def find_change_phrase(sentence: str) -> Optional[dict]: ...
def find_event_phrase(sentence: str, lexicon: Lexicon) -> Optional[tuple[str, int, int]]: ...
def has_time_word(sentence: str, allowed_spans: list[tuple[int, int]]) -> bool: ...
def has_own_date(sentence: str, allowed_spans: list[tuple[int, int]]) -> bool: ...

# arena/extract.py
def extract(pages: list[Page], lexicon: Lexicon, attrs: dict) -> list[Observation]: ...
    # attrs is B's AttrSpec map keyed (subject, attribute); use it to pick the
    # value of the expected kind when a sentence holds several.

# arena/validate.py
def validate(claim: Claim, lexicon: Lexicon) -> list[str]: ...
    # [] means the referee would accept it. Otherwise human-readable reasons.
    # Checks BOTH entry.schema.json shape AND claim-forms/value-forms grammar
    # by re-parsing claim.text against claim.form.
```

## 4. Stub rules

- A stub lives in **your** `tests/<letter>/stubs/` and is injected in your tests
  or behind an env var, never by editing another agent's file.
- A stub implements the §3 signature with the simplest behaviour that lets you
  test your own logic (e.g. C's `validate` stub only checks the JSON schema;
  B's `parse_values` stub is a regex for `€N per month` and `N <noun>`).
- Delete nothing at merge time; stubs stay in `tests/` and are harmless.

## 5. Fixtures everyone may rely on

- `data/practice.csv` and `data/lexicon.json` exist and are stable.
- `contracts/examples/**` holds 33 valid/invalid examples; A's validator must
  reproduce every verdict.
- B's `data/baked/*.json` is committed to B's branch; A and C may copy the
  files into their `tests/<letter>/fixtures/` if they need them before merge.

## 6. Merge order and integration checklist (last 3 hours before freeze)

1. Merge `agent-a/grammar` into `main`. Run `tests/a`.
2. Merge `agent-b/timelines`. Run `tests/a tests/b`.
3. Merge `agent-c/generate-runtime`. Run all tests.
4. `docker build --platform linux/amd64 -t hype .` and
   `docker run --rm --network none --memory 6g --cpus 2 --read-only --tmpfs /tmp:size=128m -v $PWD/universe:/universe:ro -v $PWD/out:/output -e ARENA_DEADLINE=$(( $(date +%s) + 600 )) hype`
   using `data/practice.csv` (renamed to `id,text,date`) as a stand-in universe.
5. Re-validate `out/output.csv` with `python -m arena.validate out/output.csv`
   (A provides this CLI). Zero invalid rows is the bar.
6. Check image size `< 3 GiB`, `USER 10001`, run time `< 10 min` with `SIGTERM` at
   minute 9 leaving a complete file.
7. Open the PR titled with the team name. Record the demo on `sample/sample.csv`
   at 10:30.

Post in the team channel with the exact signature change. All three agents must
reply "ok" before `arena/model.py` or this file changes on `main`. Each agent
then rebases. Do this at most once; after 29 Oct 08:00 the contracts are final
no matter what, and you work around them.
